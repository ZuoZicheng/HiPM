# HiPM introduction video

A responsive, video-only project page for GitHub Pages.

## Files

- `index.html`: the page, with the browser's native video controls.
- `static/videos/intro.mp4`: the introduction video, preserved at its original quality.
- `.nojekyll`: publish these static files directly.

The page has no autoplay, external scripts, analytics, or third-party fonts. The video is shown in full without cropping.

## GitHub Pages

Use repository `ZuoZicheng/HiPM`. In **Settings → Pages**, choose **Deploy from a branch**, the default branch, and **/ (root)**.

Expected site URL after deployment: https://zuozicheng.github.io/HiPM/
